# Taherun & Hannan Wedding Invitation

This is a standalone, responsive wedding invitation for Taherun Nesa Shawon
and Syed Md. Hannan (Rakib). It has a two-page book animation, event details,
and a family invitation. The current version is text-and-CSS only and does
not display wedding photos.

## Files

- `index.html` — complete page markup, styles, and behavior.
- `vercel.json` — static hosting, clean URLs, response headers, and caching.

Open `index.html` directly in a browser, or deploy this repository to Vercel.
There is no framework or build step. Bootstrap 5 and the display fonts load
from CDNs, so an internet connection is needed for those styling assets.
